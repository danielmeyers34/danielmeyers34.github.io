Job Search Log

Every application I've sent since late August 2026, what came back, and how long each one has been quiet. Open a row for the details. Want to run your own? Hit Add application — your entries save in this browser only and nothing is uploaded. Why publish this?

Three and a half weeks, about fifty applications, and no conversation with a hiring manager yet. Sending application fifty-one the same way I sent the first fifty doesn't seem like a plan, so this is the different thing: the whole log, in the open, including the silence.

Two reasons. First, numbers beat vibes — the bar on each row is how long it's been quiet, and the funnel at the top is the honest shape of a remote IT search right now. Second, if you're searching too, the page is yours: add your own applications, track the wait, export the file. If you're hiring for remote endpoint, identity, or IT operations work, or you've cracked this market recently and know what actually moved the needle, I'd like to hear it. — Daniel Meyers, LinkedIn
